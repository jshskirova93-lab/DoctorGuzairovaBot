# DoctorGuzairovaBot

Telegram-бот врача Гузаировой Гульназ Рауфовны.

## Текущее состояние

Версия: v2.1

Бот работает на Railway в режиме 24/7.

Рабочий бот:
@DoctorGuzairovaBot

Основная локальная папка проекта:
C:\CDoctorGuzairovaBot

Актуальная резервная копия:
C:\CDoctorGuzairovaBot_backup_v2.1

## Основные возможности

- Главное меню Telegram-бота.
- Информация о докторе.
- Направления лечения.
- Стоимость услуг.
- Подготовка к консультации.
- Контакты.
- Сайт.
- Анкета пациента из 7 шагов.
- Проверка неправильного ввода в анкете.
- Предпросмотр анкеты перед отправкой.
- Отправка заявки администратору.
- Ответ администратора пациенту.
- Ответ пациента администратору.
- Команда /myid.

## Переменные окружения

Для работы нужны переменные:

BOT_TOKEN
ADMIN_CHAT_ID

На Railway они задаются в разделе:

Service -> Variables

Локально они могут храниться в файле .env.

Файл .env нельзя отправлять в GitHub.

## Локальный запуск

Локальный запуск нужен только для разработки и проверки.

Перед локальным запуском нужно понимать: если бот уже работает на Railway, одновременно запускать его локально нельзя.

Команда локального запуска:

python bot.py

Остановка локального бота:

Ctrl + C

## Проверка кода

Перед коммитом выполнять:

python -m py_compile bot.py handlers.py keyboards.py texts.py

Проверка Git:

git status

## Обновление GitHub

После изменений:

git add .
git commit -m "Описание изменений"
git push

## Railway

Railway автоматически запускает новый deploy после git push в GitHub.

Проверять:

Railway -> DoctorGuzairovaBot -> Deployments

Нормальный статус:

Online
Active
Deployment successful

Если статус Crashed:

открыть Deploy Logs и смотреть последнюю строку ошибки.

## Важное правило

После успешного запуска на Railway не запускать локально:

python bot.py

Иначе один и тот же Telegram-бот будет запущен одновременно в двух местах.
